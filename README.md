# CourseForge Studio

AI-assisted e-learning authoring for Windows. Build slide courses (states, layers, triggers, variables, quizzes) or scrolling lessons courses. Let Claude draft, review and fix them. Publish to offline Web or SCORM 1.2.

> Work in progress. Install instructions arrive with the first release.

## Develop
```bash
npm ci
npm test
npm run e2e
npm run cf -- app
```
