The files are part of CourseForge Studio and are released under the MIT License (see `LICENSE` at the repository root). Each SVG starts with the comment `CourseForge Studio library: original artwork drawn for CourseForge Studio. Licence: MIT (see LICENSE at the repository root and packages/library/LICENSE.md)` so a copied file keeps its origin. `tests/unit/library.test.js` checks that marker and the safety rules above on every file.
